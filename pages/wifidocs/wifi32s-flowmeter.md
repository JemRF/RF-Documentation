## Introduction
The WiFi S32 Sensor support a digital interface that can be used for an external contact closure (see External Switch) or flow meter. 

This configuration guide explains how to use the digital interface to sense to use and measure fluid flow with an external flowmeter. The sensor suport a dry contact flowmeter and counts rotations per minute.\
When enabled, the Sensor Config page will show an additional sensor called "FlowMeter" with a value of counts per minute or gallons per minute. There is a new control field use the calibrate tne counts per minute to gallons per minute. When the contol field is 0 the displayed value is counts per minute.


## Quick Start
When option is purchased the sensor will have a 3 pin JST 2.5 connection installed and include a 6 inch 3 pin cable with a JST 2.5 connection to interface the external flowmeter.
